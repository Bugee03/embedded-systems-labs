# Sözlük — kısaltmalar (EN tam adı · RU anlamı · TR)

| Kısaltma | English | Русский (смысл) | Türkçe |
|---|---|---|---|
| FPGA | Field-Programmable Gate Array | программируемая логическая матрица | Sahada programlanabilir kapı dizisi |
| ASIC | Application-Specific Integrated Circuit | заказная микросхема | Uygulamaya özel tümdevre |
| HDL | Hardware Description Language | язык описания аппаратуры | Donanım tanımlama dili |
| RTL | Register-Transfer Level | уровень регистровых передач | Register'lar arası veri akışı seviyesi |
| LUT | Look-Up Table | таблица истинности (память вместо логики) | Arama tablosu — FPGA'nın mantık hücresi |
| FF | Flip-Flop | триггер (хранит 1 бит) | 1 bitlik bellek elemanı |
| CLB | Configurable Logic Block | конфигурируемый логический блок | 2 slice'tan oluşan blok |
| BRAM | Block RAM | блочная память внутри ПЛИС | Gömülü blok bellek (36 Kb) |
| DSP48E1 | Digital Signal Processing slice | блок умножения-накопления | Çarpma-toplama donanım bloğu |
| MAC | Multiply-Accumulate | умножение с накоплением | Çarp-topla |
| IOB | Input/Output Block | блок ввода-вывода | G/Ç bloğu |
| XDC | Xilinx Design Constraints | файл ограничений (пины, частоты) | Kısıt dosyası |
| JTAG | Joint Test Action Group (IEEE 1149.1) | интерфейс программирования/отладки | Programlama/debug arayüzü |
| STA | Static Timing Analysis | статический временной анализ | Statik zamanlama analizi |
| WNS / TNS | Worst / Total Negative Slack | худший / суммарный запас по времени | En kötü / toplam negatif pay |
| MMCM / PLL | Mixed-Mode Clock Manager / Phase-Locked Loop | генераторы/умножители тактовой частоты | Saat üretici/çarpıcı |
| CDC | Clock Domain Crossing | переход между тактовыми доменами | Saat alanları arası geçiş |
| FSM | Finite State Machine | конечный автомат | Sonlu durum makinesi |
| FIFO | First-In First-Out | очередь (буфер) | İlk giren ilk çıkar tamponu |
| IP | Intellectual Property core | готовый блок от производителя | Hazır tasarım çekirdeği |
| ILA | Integrated Logic Analyzer | встроенный логический анализатор | Dahili lojik analizör |
| XADC | Xilinx Analog-to-Digital Converter | встроенный АЦП | Dahili ADC (12-bit, 1 MSPS) |
| ADC / DAC | Analog-to-Digital / Digital-to-Analog Converter | АЦП / ЦАП | Analog→dijital / dijital→analog |
| UART | Universal Asynchronous Receiver-Transmitter | последовательный порт | Seri haberleşme |
| LFSR | Linear-Feedback Shift Register | сдвиговый регистр с обратной связью (псевдошум) | Sözde-rastgele üreteç |
| NCO / DDS | Numerically Controlled Oscillator / Direct Digital Synthesis | цифровой генератор синуса | Sayısal osilatör |
| FIR | Finite Impulse Response | фильтр с конечной импульсной характеристикой | Sonlu dürtü yanıtlı filtre |
| CIC | Cascaded Integrator-Comb | фильтр-дециматор без умножителей | Çarpıcısız decimation filtresi |
| CORDIC | COordinate Rotation DIgital Computer | вычисление угла/амплитуды сдвигами | Döndürme ile açı/genlik hesabı |
| FFT | Fast Fourier Transform | быстрое преобразование Фурье | Hızlı Fourier dönüşümü |
| IQ | In-phase / Quadrature | синфазная / квадратурная составляющие | Faz-içi / dik bileşen |
| PRF / PRI | Pulse Repetition Frequency / Interval | частота / период повторения импульсов | Darbe tekrar frekansı / aralığı |
| LFM | Linear Frequency Modulation (chirp) | линейная частотная модуляция | Doğrusal frekans modülasyonu |
| FMCW | Frequency-Modulated Continuous Wave | непрерывный сигнал с ЧМ | Frekans modülasyonlu sürekli dalga |
| MTI | Moving Target Indication | селекция движущихся целей | Hareketli hedef göstergesi |
| CFAR | Constant False Alarm Rate | постоянный уровень ложных тревог | Sabit yanlış alarm oranı |
| SFDR | Spurious-Free Dynamic Range | динамический диапазон без паразитов | Sahte bileşensiz dinamik aralık |
| Qm.n | fixed-point format (m integer, n fractional bits) | формат с фиксированной точкой | Sabit noktalı sayı formatı |
