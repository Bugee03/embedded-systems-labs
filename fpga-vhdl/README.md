# 🔬 VHDL Lab — Digital Design Practice

This repository contains structured VHDL practice projects covering
basic to intermediate digital design concepts.

It is focused on learning:

- Digital logic design
- RTL modeling
- Testbench writing
- Simulation workflow
- FPGA-oriented thinking

---

# 📂 Project Structure

vhdl_lab/
│
├── Chapter1/ # Basic logic gates & combinational circuits
├── Chapter3/ # Sequential logic & flip-flops
├── my_first/ # First VHDL experiments
├── test/ # Testbench files
├── LICENSE
└── README.md

# 🧠 Topics Covered

## ✅ Combinational Logic
- AND / OR / NOT
- NAND / NOR
- XOR
- Multiplexers
- Simple arithmetic circuits

## ✅ Sequential Logic
- D Flip-Flop
- Counters
- Registers
- Clocked processes

## ✅ Testbenches
- Simulation setup
- Signal forcing
- Clock generation
- Verification logic

---

# 🛠 Tools Used

- VHDL (IEEE 1164 standard)
- ModelSim / QuestaSim
- Vivado (optional FPGA synthesis)

---

# 🚀 How to Run Simulation

Example (ModelSim):
vcom file.vhd
vsim work.entity_name
run -all
