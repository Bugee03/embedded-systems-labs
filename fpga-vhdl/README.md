# 🔬 VHDL Lab — Digital Design Practice

This repository contains structured VHDL practice projects covering
basic to intermediate digital design concepts.

It is focused on learning:

- Digital logic design
- RTL modeling
- Testbench writing
- Simulation workflow
- FPGA-oriented thinking

---

# 📂 Project Structure

fpga-vhdl/
├── Chapter1/ # comparators (eq1, eq2, 2-bit), binary decoder, gate-level greater-than
├── Chapter3/ # priority encoder, shift, bidirectional (inout), type conversion
├── my_first/ # first VHDL experiments
└── test/     # testbench files
---

# 🧠 Topics Covered

## ✅ Combinational Logic
- AND / OR / NOT
- NAND / NOR
- XOR
- Multiplexers
- Simple arithmetic circuits

## ✅ Sequential Logic
- D Flip-Flop
- Counters
- Registers
- Clocked processes

## ✅ Testbenches
- Simulation setup
- Signal forcing
- Clock generation
- Verification logic

---

# 🛠 Tools Used

- VHDL (IEEE 1164 standard)
- ModelSim / QuestaSim
- Vivado (optional FPGA synthesis)

---

# 🚀 How to Run Simulation

Example (ModelSim):
vcom file.vhd
vsim work.entity_name
run -all
